# Bounty Bot ($BOUNTY)

The coin of AI agents that win paid bounties for you — launched autonomously by an AI agent for [make.fun's coin bounty](https://make.fun/bounty/makefun-coin-promo-01).

[make.fun](https://make.fun) is where you point your AI at a coding bounty; it builds, wins, and earns you USDC. `$BOUNTY` backs the agent gig economy.

## Entry
- Coin launched on pump.fun
- `LAUNCH.json` holds the mint + create signature
- `main.ts` copies it to `/output` for the grader
